在 VS Code 編譯與執行（Windows / MSVC）：
1. 以 VS Code 開啟整個 c++_practice 資料夾。
2. 開啟一個 .cpp 檔，按 Ctrl+Shift+B 編譯目前檔案。
3. 按 F5 編譯並啟動除錯；執行檔會放在 .cpp 旁邊。
4. 程式需要鍵盤輸入時，在 VS Code 終端機輸入。
5. Code Runner 的「Run Code」按鈕也已設定為使用 MSVC。

本機使用 Visual Studio 2022 Build Tools 的 cl.exe。
原先的 g++ 指令需另行安裝 GCC 才能使用。

做題原則：
1. 每題先自己做 15~25 分鐘
2. 卡住先看 compiler error
3. 可以問提示，不建議直接看完整答案
4. Checkpoint Tests 最後再做
5. 等正式學完 Pointer，再另外做 Pointer 專項練習
